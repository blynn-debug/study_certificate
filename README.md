# study_certificate

자격증 학습 자료와 학습법 분석, 생성한 PDF·HTML 문제지를 보관합니다.

## 전체 스냅샷

- 원본 파일: 5,636개, 1,762,686,018바이트
- 원래 폴더 구조와 파일 내용을 유지했습니다.
- 요청에 따라 원문 자료, 분석 결과, 백업, 캐시, 가상환경과 도구 파일도 포함했습니다.
- 업로드 설정 및 검증을 위해 README.md, .gitattributes, FILE_MANIFEST.json을 추가했습니다.
- FILE_MANIFEST.json에는 원본 파일별 경로·크기·SHA-256이 기록되어 있습니다.

## 전체 파일 내려받기

큰 파일 6개는 Git LFS로 저장했습니다. Git LFS를 설치한 뒤 다음과 같이 내려받습니다.

```sh
git lfs install
git clone <이 저장소의 Git URL>
cd study_certificate
git lfs pull
```

HTML 인쇄 시 A4, 배경 그래픽 켜기, 크롬 여백 ‘없음’을 사용합니다.
